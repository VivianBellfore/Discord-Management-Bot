# LCNET-Management-Bot
Discord community bot for one or multiple guilds.
Needs to be hosted and also needs an MySql data base and a C# IDE for editing.

<br>

# Installation
- Build a bot on the Discord Developer Portal. ( https://discord.com/developers/applications )
- Change and add informations in the `Configurations.cs`.
- Build the project and place it on your host/server.
- Use the sql file to build the data base structure for the bot.
- Start the bot console with the exe.
- Add the bot to your discord guild trough the Discord Developer Portal.
- Get a GDPR for your users, as this bot is saving user data that may be protected in many countries.
